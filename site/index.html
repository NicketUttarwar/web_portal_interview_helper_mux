Zero Shot Media

In AI, zero shot means a model is asked to handle a task it was not trained on and is not shown any worked examples of that task. The request itself is the whole specification. The model answers from what it already learned, without a fine-tune on labeled examples and without a few sample answers placed in the prompt. Showing those samples would be few-shot. Changing the model on a set of examples of the task would be fine-tuning.
